# MG-AUD-093

Title

Public validation accepts nonexistent chemical symbols

Status

✅ Resolved

Resolution Version

Post-v1.9.18

Affected Components

- Canonical periodic-table domain data
- Shared discovery element-filter dependency
- Seven discovery GET routes
- `avoid_element` and `prefer_element` query parameters
- Domain and API regression tests

Root Cause

Public discovery routes applied only string-length constraints to element
filters. Structurally valid but nonexistent symbols could therefore enter
discovery processing. The database could not serve as the validator because
its element table contains only the subset currently represented by imported
MaterialGraph data, not the full periodic table.

Resolution

✓ Added a centralized catalogue of all 118 recognized chemical element
symbols.

✓ Added canonical symbol normalization, including conventional casing and
surrounding-whitespace normalization.

✓ Added one shared FastAPI dependency that validates and normalizes both
element-filter parameters.

✓ Applied the dependency consistently to candidates, chains, graph, subgraph,
path, connected-community, and modularity-community routes.

✓ Preserved the distinction between chemical legitimacy and dataset coverage:
a valid symbol such as `Cu` is accepted even when no current material record
uses it, while an unknown symbol such as `Xx` returns `422`.

Regression Verification

✓ Domain tests verify that the catalogue contains exactly 118 symbols,
including `H` and `Og`, and that every canonical symbol normalizes to itself.

✓ Domain tests verify mixed-case normalization, surrounding-whitespace
normalization, and rejection of nonexistent symbols.

✓ API regressions cover all seven affected routes and both element-filter
parameters.

✓ The focused tests, full regression suite, and Ruff checks passed.

API Contract

Yes. Nonexistent chemical symbols now receive `422`, and accepted symbols are
normalized before reaching discovery services. Valid symbols are not rejected
merely because MaterialGraph has no current dataset coverage for them.

Database Migration

No.

Scientific Impact

Invalid element-filter requests can no longer influence discovery results.
No scoring, ranking, graph, or pathway algorithm changed. This remediation
validates symbol identity only; it does not claim that MaterialGraph contains
research data for every recognized element.

Lessons Learned

Chemical-domain validity and current database coverage are separate concerns
and require separate representations. A partial research dataset must not be
used as the authority for the existence of chemical elements.
