# Material Explorer (read-only milestone)

Run the FastAPI backend locally at `http://127.0.0.1:8000`, then from this directory run `npm install` and `npm run dev`. Commit the generated `package-lock.json` after successful installation. Vite proxies `/api` to the local backend. For another API origin set `VITE_API_BASE_URL` at build time; that origin must explicitly allow browser requests. No write endpoints are called.

Run `npm run build` to check strict TypeScript and produce the static bundle, then `npm test` to verify API request and failure handling. This milestone displays the first 100 materials and allows paging and direct lookup by **local numeric ID**. Filtering applies only to loaded pages; the backend has no search endpoint. URL `?material=<id>` opens a material directly.

The candidates endpoint uses its existing soft avoid/prefer semantics and existing backend ordering. Score numbers are internal rule scores. The material detail response includes a source label but no per-property provenance or evidence quality; the UI says so. Neither endpoint supplies dataset or methodology versions, rank groups, coverage, completeness status, or saved investigation identity. The UI does not fabricate those fields or claim a scientific tie. No domain-specific objective defaults are applied.

The separate Objective Investigation form sends a structured JSON `POST` to `/materials/{id}/discovery/objective/explore`. Its single result-limit control sends the same value for both `objective.limit` and the top-level `limit`: in this route the top-level limit caps both returned ranked materials and pathways, while `objective.limit` is reported as the underlying requested chain limit but does not independently truncate the ranked search pool. `generated_chain_count` counts chains before objective filters; `returned_chain_count` counts pathways included in the response. `result_truncated` and `search_truncated` are separate and neither establishes scientific completeness. Ranked materials may lack a pathway among the returned subset. Objective scores and pathway usefulness scores are distinct rule values, separate from discovery scores and experimental confidence.
